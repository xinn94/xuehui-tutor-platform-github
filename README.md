# 學匯｜家教媒合平台

學匯是一個師生雙向家教媒合平台展示專案。學生可以刊登學習需求、尋找老師；老師可以展示教學資訊、瀏覽學生需求。雙方提出聯繫申請並經對方同意後，才進一步建立聯繫。

## 本機啟動

需要先安裝 Node.js（建議使用 LTS 版本）。

```bash
npm install
npm run dev
```

依照終端機顯示的網址開啟網站，通常是 `http://localhost:5173`。

## 建置

```bash
npm run build
npm run preview
```

建置完成的靜態檔案會輸出至 `dist/`。

## 功能

- 首頁、教師列表、學生需求列表、介紹頁。
- 教師與學生／家長兩種展示登入身分。
- 搜尋與依學習階段、科目篩選。
- 學生發布、管理及下架需求。
- 教師建立及編輯展示用教師資料。
- 聯繫申請、接受、拒絕與狀態管理。
- 使用 localStorage 保存目前瀏覽器中的展示資料。

## 重要限制

目前登入與資料管理均為前端展示功能，不是真正的帳號驗證或跨裝置資料庫。localStorage 不能提供真正的隱私保護，也不能作為真實使用者個資的安全儲存方式。若要正式上線，必須串接後端／BaaS、身份驗證及伺服器端存取權限。

所有初始人物與需求皆為虛構資料。請勿在展示版輸入真實個人資訊。

## GitHub Pages

此專案使用 Vite。部署至 GitHub Pages 前，若專案網址會位於 `https://<帳號>.github.io/<repo>/`，請在 `vite.config.js` 設定正確的 `base: '/<repo>/'`，並使用適合的部署流程將 `dist/` 發布至 Pages。
